## 1. Функциональные требования

| ID | Функциональность | Описание | Источник |
| --- | --- | --- | --- |
| FR-001 | Авторизация пользователя | Система предоставляет форму авторизации, содержащую поле Email, поле Password и кнопку Login | Confluence 1376257 (FR-001) |
| FR-002 | Авторизация пользователя | Пользователь может ввести email в поле Email | Confluence 1376257 (FR-002) |
| FR-003 | Авторизация пользователя | Пользователь может ввести пароль в поле Password | Confluence 1376257 (FR-003) |
| FR-004 | Авторизация пользователя | При нажатии Login система проверяет введённые учётные данные | Confluence 1376257 (FR-004) |
| FR-005 | Авторизация пользователя | При успешной авторизации система создаёт пользовательскую сессию и перенаправляет пользователя на главную страницу | Confluence 1376257 (FR-005) |
| FR-006 | Авторизация пользователя | При вводе неверных учётных данных система не создаёт пользовательскую сессию | Confluence 1376257 (FR-006) |
| FR-007 | Обработка ошибок | При недоступности сервера система сообщает пользователю о невозможности выполнить авторизацию | Confluence 1376257 (ERR-002) |
| FR-008 | Обработка ошибок | После неуспешной авторизации пользователь остаётся на странице авторизации | Confluence 1376257 (ERR-003) |

## 2. Бизнес-правила

| ID | Правило | Относится к требованию | Источник |
| --- | --- | --- | --- |
| BR-001 | Поле Email является обязательным | FR-001, FR-002 | Confluence 1376257 (VAL-001) |
| BR-002 | Поле Password является обязательным | FR-001, FR-003 | Confluence 1376257 (VAL-002) |
| BR-003 | Email должен соответствовать допустимому формату email | FR-001, FR-002 | Confluence 1376257 (VAL-003) |
| BR-004 | При попытке авторизации с незаполненными обязательными полями система отображает сообщение об ошибке | FR-001, FR-004 | Confluence 1376257 (VAL-004) |
| BR-005 | При неверном email или пароле система отображает сообщение: "Invalid email or password." | FR-004, FR-006, FR-008 | Confluence 1376257 (ERR-001) |

## 3. Ограничения

| ID | Ограничение | Тип | Источник |
| --- | --- | --- | --- |
| CON-001 | Пароль не должен отображаться в открытом виде при вводе (поле пароля должно быть маскировано) | Безопасность (UI) | Confluence 1376257 (SEC-001) |
| CON-002 | Система не должна раскрывать, существует ли указанный email в системе, если учётные данные неверны | Безопасность (конфиденциальность) | Confluence 1376257 (SEC-002) |
| CON-003 | Пароль не должен передаваться или храниться в открытом виде (шифрование при передаче и хранении) | Безопасность (передача/хранение) | Confluence 1376257 (SEC-003) |
